# Trade & library sell-in

*Roster skill S27. Preloaded into: `publicity-community-relations-lead`, `sales-distribution-manager`, `trade-library-marketing-specialist`.*

## Purpose
Sell-in determines whether a book is on shelves on publication day.

## Toolkit (docs/07)
- **Seasonal catalogs** (Spring/Fall) on **Edelweiss+**, with complete metadata and comps.
- **Tip sheets** for sales reps: one-line pitch, comps, audience, marketing commitments, and author platform.
- **ARCs:** NetGalley and Edelweiss digital review copies, plus print ARCs for key booksellers and librarians.
- **Trade reviews:** PW, Kirkus, Library Journal, Booklist, Shelf Awareness. Submit **3–4 months before publication**. Library buyers rely on them.
- **Booksellers:** ABA Winter Institute, **SIBA** (Southern Independent Booksellers Alliance) shows, and Indie Next List nominations (bookseller-driven).
- **Libraries:** ALA conferences, Florida Library Association, Palm Beach County Library System, LibraryReads, and OverDrive/Libby and other library platforms.

## Method
1. Finalize metadata and catalog copy by T−6–9 months.
2. Prepare the tip sheet and present at the distributor's sales conference.
3. Run ARC distribution with a target list, and track reviews.
4. Do targeted outreach to 30–50 key indie booksellers and library collection managers.
5. Monitor initial orders by account against plan. Adjust the print run and marketing.

## Output
Tip sheets, catalog copy, ARC distribution plan, review submission tracker, and a sell-in report.
